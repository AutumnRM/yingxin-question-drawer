# 迎新互动抽题器

面向高校社团迎新活动的单页抽题工具。页面无需后端服务，打开后即可在浏览器中完成随机抽题、参考答案展示、活动登记和记录导出。

在线地址：[https://autumnrm.github.io/yingxin-question-drawer/](https://autumnrm.github.io/yingxin-question-drawer/)

## 功能

- 简单模式：面向非专业学生，包含泛计算机、反诈防骗、泛数码和基础知识。
- 困难模式：从原有题库中筛选中偏硬核知识点，适合进阶提问。
- 支持连续抽题，题目默认抽过不放回；抽完后自动重新洗牌。
- 支持切换为“放回，允许重复”。
- 支持显示/隐藏参考答案、点击题目翻看答案、倒计时和全屏。
- 支持按分类启用或停用题目。
- 点击“完成”后登记本轮信息，并将本轮抽到的题目写入记录。
- 支持导出 CSV，字段包括姓名、学号、联系信息、分类、题目和抽题时间。
- 支持深色/浅色主题。

## 使用方法

1. 打开在线地址或直接打开 index.html。
2. 点击“简单模式”或“困难模式”开始抽题。
3. 使用“显示答案”查看参考答案；也可以点击题目卡片。
4. 可以连续抽取多道题。
5. 本轮结束后点击“完成”，填写姓名、学号和可选的联系信息。
6. 活动结束后进入“设置”，导出 CSV 记录。

### 快捷键

| 按键 | 功能 |
| --- | --- |
| 1 | 简单模式 |
| 2 | 困难模式 |
| Enter | 显示/隐藏答案 |
| End | 完成本轮并登记 |
| R | 重置当前抽题进度 |
| F | 切换全屏 |
| Esc | 关闭弹窗或设置面板 |

## 题库结构

题库直接写在 index.html 的 JavaScript 中，每道题包含以下字段：

~~~js
{ c: "general", s: 1, q: "问题文本", a: "参考答案" }
~~~

- c：分类标识，对应 CATS 中的分类。
- s：难度等级。s >= 2 的非开放题会进入困难模式，其余题目进入简单模式。
- q：题目内容。
- a：参考答案。

当前题库包含原有题目，以及新增的泛计算机、反诈防骗、泛数码、网络生活、数据结构、操作系统、组成原理和编程工程内容。

## 数据持久化与隐私

项目使用浏览器 localStorage 保存数据，不使用服务器数据库：

- draw-records：本机的抽题登记记录。
- draw-theme：深色/浅色主题设置。

记录只保存在当前浏览器的本机存储中，不会自动上传到 GitHub 或其他服务器。更换浏览器、清理网站数据或使用隐私模式可能导致记录不可见，因此应在活动结束后及时导出 CSV。

## 项目结构

~~~text
.
├── index.html                    # 页面、样式、交互逻辑和题库
└── .github/
    └── workflows/
        └── pages.yml             # GitHub Pages 自动部署
~~~

这是一个纯静态项目，不需要安装依赖或运行构建工具。

## 本地运行

直接双击 index.html 即可使用。若需要通过本地 HTTP 服务运行，可在项目目录执行：

~~~bash
python -m http.server 8000
~~~

然后访问 http://localhost:8000/。

## 发布到 GitHub Pages

项目已配置 .github/workflows/pages.yml。向 main 分支推送更新后，GitHub Actions 会自动部署到：

~~~text
https://autumnrm.github.io/yingxin-question-drawer/
~~~

也可以在 GitHub Actions 页面手动运行 Deploy to GitHub Pages 工作流。

## 修改题库

编辑 index.html 中的 QUESTIONS 或 EXTRA_BANK_* 数组即可添加、删除或修改题目。新增分类时，需要同时在 CATS 中增加分类配置，例如：

~~~js
newCategory: { name: "新分类", en: "New Category" }
~~~

新增题目后建议检查：

1. c 是否已经在 CATS 中定义。
2. q 和 a 是否填写完整。
3. s 是否符合预期模式。
4. 页面能否正常抽题和显示答案。
5. CSV 是否包含所需字段。
